# Measured experiment results

- `final_test/`: original frozen held-out results, bootstrap tables, diagnostics,
  and trained-model coefficient/importance summaries.
- `figures/`: original held-out failure figure.
- `model_selection/`, `pca_validation/`, `baseline_training/`: validation and
  training diagnostics; these are not held-out test results.
- `reproduction/`: ignored generated outputs from the README commands. These
  are written separately so the original reference results remain unchanged.

See the root README for exact reproduction commands and expected headline counts.
